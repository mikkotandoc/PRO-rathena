## Common Player Atcommands

Availability depends on your **group level** in `conf/groups.yml`. Below are typical player-accessible commands on rAthena servers.

| Command | Description |
|---------|-------------|
| `@autoloot` | Toggle auto-loot all drops |
| `@alootid +<item id>` | Add item to autoloot list |
| `@alootid -<item id>` | Remove item from autoloot list |
| `@aloottype` | Autoloot by item type |
| `@autoloottype` | Toggle autoloot types |
| `@go <city>` | Warp to preset town |
| `@where` | Current map and coordinates |
| `@time` | Server time |
| `@jailtime` | Remaining jail time (if jailed) |
| `@exp` | Show current EXP progress |
| `@stats` | Show stat bonuses |
| `@commands` | List available commands for your group |
